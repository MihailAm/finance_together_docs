
# Введение
Приложение "Семейный Бюджет" разработано для упрощения управления личными и групповыми финансами. Оно позволяет пользователям отслеживать доходы и расходы, планировать бюджет, ставить финансовые цели и анализировать свои финансовые привычки. Приложение поддерживает работу с группами, где участники могут совместно управлять общими финансами.
