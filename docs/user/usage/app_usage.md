# Использование приложения

## Для администратора группы
1. Создайте группу, указав её название и добавив участников.
2. Управляйте участниками группы: меняйте роли, добавляйте новых или удаляйте существующих.
3. Отслеживайте общие расходы и доходы группы.

## Для обычного пользователя
1. Участвуйте в группах, созданных администратором.
2. Добавляйте свои доходы и расходы, указывая категории и суммы.
3. Создавайте финансовые цели и отслеживайте их выполнение.
4. Управляйте личными долгами и получайте напоминания о погашении.
5. Планируйте свои покупки.

## Для гостя
1. Зарегистрируйтесь или войдите в систему, чтобы получить доступ к полному функционалу приложения.
